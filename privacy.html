Privacy Policy

Personal Google Drive rclone
Effective: October 13, 2026

Purpose and scope

This policy describes the personal Google OAuth application named Personal Google Drive rclone. It exists to let its owner connect the open-source rclone program running on a Linux computer to the owner's Google Drive. It is not a hosted file processing service and does not offer accounts to the public.

Google user data accessed

When the owner authorizes the application, rclone requests the https://www.googleapis.com/auth/drive scope. This permission allows rclone to list and read Google Drive files and metadata, and to create, modify, move, and delete files, as directed by the owner. These operations occur through the Google Drive API.

How the data is used

Google Drive file contents and metadata are accessed only to provide the owner's requested rclone operations, such as browsing a mounted folder or synchronizing files. The owner controls the rclone installation and file operations. The OAuth credentials and tokens are kept in local configuration files on the owner's device. Drive data may be stored locally as part of normal file access, syncing, or rclone caching.

Data disclosure and sharing

This personal OAuth setup does not send Google Drive file contents or OAuth tokens to this informational website or to a separate application developer-operated server. It does not sell Google user data, use it for advertising, or share it with third parties for unrelated purposes. Google processes its own API traffic under Google's policies. GitHub hosts this informational website and may process ordinary web request information under its own privacy policy; GitHub Pages does not receive Drive files through this application.

Retention and security

Locally downloaded or cached files remain on the owner's device until the owner deletes or changes them. Locally stored OAuth tokens remain in the rclone configuration until removed, revoked, or otherwise invalidated. The configuration is stored with restricted local file permissions. No user-data database is maintained by this informational website.

Access and revocation

The owner can stop using the connection by removing the rclone remote and any cached or synchronized local files. Google Drive access can also be revoked from the Google Account's third-party apps and services settings. Revoking access prevents new authorized Drive API access by this OAuth connection.

Limited use

Use of data obtained through Google APIs is limited to supplying the file access and synchronization features explicitly initiated by the owner, consistent with the Google API Services User Data Policy, including its Limited Use requirements.

Contact

For a question or concern about this personal OAuth application's privacy practices, open an issue in its public GitHub repository. Do not include confidential Google Drive information, passwords, or access tokens in an issue.
