Personal Google Drive rclone

Information about a personally operated Google Drive connection

What this application does

This is a personal Google OAuth application used to authorize rclone, an open-source file synchronization and mount tool, to access its owner's Google Drive from a Linux computer.

It enables the owner to browse, open, create, update, move, and delete their own Google Drive files through rclone, including a locally mounted Drive folder in the Linux file manager. It is not a general-purpose product or a public service.

Why Google Drive access is requested

The client requests Google Drive access because rclone needs to read and write the files the owner chooses to work with. The requested https://www.googleapis.com/auth/drive scope permits access to Drive files. Access is granted only after the owner signs in with Google and approves the permission request.

Who can use it

The application is intended for the owner's personal use, not for unrelated users. It has no public login, registration, or account management system.

Data handling

The OAuth application connects rclone directly to the Google Drive API. Authentication tokens are stored in the owner's local rclone configuration, not on this website. This informational website does not ask for Google credentials or receive the contents of Google Drive files.

For information on access, storage, sharing, and revocation, see the Privacy Policy.

Independent personal configuration of rclone. Not affiliated with Google or the rclone project.
